# 일별 체크리스트 세트 편집기 설계

## 목표

업무 체크리스트 화면의 넓은 세트 패널을 우측 상단의 `체크리스트 세트` 토글로 대체한다. 공용 기본 세트는 제공하지 않으며, 사용자가 새 세트를 만들 때 시작일 기준 30일의 일별 업무를 여러 개씩 구성한다.

## 세트 접근 방식

- 업무 체크리스트 화면 우측 상단 여백에 `체크리스트 세트` 토글 버튼을 둔다.
- 토글을 열면 저장된 공용 세트 목록, 현재 업체 적용, 수정, 새 세트 버튼을 표시한다.
- 처음에는 세트 목록을 비워 둔다.

## 새 세트 편집기

- 새 세트와 수정은 넓은 전용 편집 화면에서 처리한다.
- 세트 이름과 설명을 입력한다.
- 좌측 구간 선택은 `1주차`, `2주차`, `3주차`, `4주차`, `마무리`다.
- 1~4주차는 각각 1일차~7일차를 보여 준다.
- 마무리는 29일차·30일차만 보여 준다.
- 각 일자에는 업무를 여러 개 추가, 삭제, 정렬할 수 있다.
- 세트 적용 시 각 업무를 업체 전용 복사본으로 만들고, 업체 시작일에 맞는 실제 달력 날짜에 배치한다.

## 호환성과 검증

- 기존 주차 단위 체크리스트와 세트는 삭제하지 않고 기존 방식으로 계속 표시한다.
- 기존 세트가 있으면 항목은 각 주차의 첫날에 배치해 읽을 수 있게 유지한다.
- 같은 일자에 여러 업무가 저장·적용·달력 팝업 표시되는지 검증한다.
- 빈 세트 목록, 30일차 마무리, 업체 시작일이 월 중간인 경우를 검증한다.
