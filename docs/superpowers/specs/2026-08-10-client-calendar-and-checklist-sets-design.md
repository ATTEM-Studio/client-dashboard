# 업체 일정 달력과 체크리스트 세트 설계

## 목표

업체 상세 화면의 주차별 진행 영역을 월간 일정 달력으로 교체한다. 달력은 업무를 수정하는 도구가 아니라, 적용된 체크리스트를 날짜별로 확인하고 특이사항 메모를 기록하는 화면으로 사용한다.

## 화면 구조

업체 상세의 기본 탭은 `일정 달력`, `업무 체크리스트`, `리포트`로 구성한다.

- **일정 달력:** 선택 월의 달력을 크게 표시한다. 날짜를 누르면 팝업에서 해당 날짜의 주차 구간에 배정된 체크리스트 항목을 읽기 전용으로 보여 주고, 특이사항 메모만 입력·수정·저장한다.
- **업무 체크리스트:** 체크리스트 전용 화면으로 이동한다. 내부 탭은 `현재 업체 업무`와 `체크리스트 세트`다.
- **리포트:** 기존 주간·월간 리포트 기능을 유지한다.

## 공용 체크리스트 세트

`체크리스트 세트`는 어느 업체의 업무 체크리스트 화면에서 열어도 같은 공용 템플릿 보관함을 보여 준다.

- 기본 공용 세트와 사용자가 만든 세트를 함께 보여 준다.
- 사용자는 세트 이름과 설명을 정하고 항목을 추가·수정·삭제할 수 있다.
- 각 항목은 `1주차`, `2주차`, `3주차`, `4주차`, `마무리` 중 하나에 배정한다.
- `마무리`는 업체 시작일 기준 29~30일이다.
- 세트를 현재 업체에 적용하면 업체 전용 복사본을 만든다. 이후 완료 처리나 업체별 항목 조정은 공용 원본 및 다른 업체에 영향을 주지 않는다.

## 달력과 메모

- 달력의 각 날짜는 업체 시작일을 기준으로 주차 또는 마무리 구간을 계산한다.
- 해당 구간에 배정된 현재 업체의 체크리스트 항목을 날짜 팝업에서 확인한다.
- 날짜 팝업은 항목 완료 상태를 바꾸거나 항목을 편집하지 않는다.
- 각 업체에는 날짜를 키로 하는 특이사항 메모를 저장한다. 메모가 있는 날짜는 달력에 표시한다.
- 시작일 이전 및 30일 이후 날짜는 업무 항목 없이 메모만 기록할 수 있다.

## 데이터와 호환성

- 기존 업체의 `checklist`와 `progress` 데이터는 보존한다.
- 기존 체크리스트 항목의 `week` 값은 동일한 주차 구간으로 달력에서 읽는다.
- 공용 세트는 별도 저장소 키로 관리하고, 업체 적용본은 해당 업체 데이터 안에 저장한다.

## 검증 기준

- 세트를 만든 뒤 다른 업체의 업무 체크리스트 화면에서도 동일한 세트가 보인다.
- 세트를 적용한 업체의 완료 처리는 다른 업체와 공용 원본에 영향을 주지 않는다.
- 1~4주차와 마무리(29~30일) 날짜가 올바른 항목을 표시한다.
- 날짜 팝업에서 메모를 저장하면 해당 날짜에 메모 표시가 나타나고, 다시 열었을 때 내용이 유지된다.
- 기존 리포트 및 기존 체크리스트 데이터가 유지된다.
