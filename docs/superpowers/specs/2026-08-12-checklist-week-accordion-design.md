# Checklist Week Accordion Design

## Goal

업체 상세의 `업무 체크리스트` 탭을 주차별 접이식 구조로 바꿔, 현재 업체 업무를 한눈에 구분하고 필요한 주차만 펼쳐 관리한다.

## Design

- 업무는 `1주차`, `2주차`, `3주차`, `4주차`, `마무리`, `미배정` 순서로 그룹화한다.
- 일별 업무(`day`)는 기존 기간 계산을 사용해 주차를 정한다. 29~30일차는 `마무리`로 묶는다.
- 기존 주차 업무(`week`)는 기존 주차 값을 그대로 따른다.
- 각 그룹 헤더에는 `완료/전체` 숫자를 표시하고, 버튼처럼 눌러 접고 펼친다.
- 기본 상태는 현재 진행 기간과 미완료가 있는 그룹을 열어둔다. 사용자가 토글한 상태는 화면 이동 전까지 유지한다.
- 빈 그룹은 기본적으로 숨기되, 미배정 그룹은 업무가 있을 때만 보여준다.
- 기존 업무 완료/삭제/직접 추가/체크리스트 세트 적용 기능은 유지한다.

## Error Handling

- 시작일이 없거나 기간 계산이 불가능한 일별 업무는 `미배정`으로 보여준다.
- 접힌 그룹 안에 미완료 업무가 있으면 헤더 숫자로 상태를 알 수 있게 한다.

## Testing

- 그룹 순서와 라벨을 검증한다.
- 같은 주차의 여러 업무가 한 그룹에 함께 렌더링되는지 검증한다.
- 토글 버튼과 `aria-expanded` 상태를 검증한다.
- 기존 완료/삭제/추가 버튼 속성이 유지되는지 검증한다.
