# 키워드 그래프 가독성 개선 설계

## 목표

키워드 검색량 그래프의 요약 수치와 기간별 표를 빠르게 읽고 비교할 수 있게 한다.

## 요약 카드

- 핵심 지표명과 숫자를 가장 강하게 표시한다.
- `월평균 검색량` 아래에는 `최근 1년 기준`을 작고 연한 보조 문구로 표시한다.
- `주평균 검색량` 아래에는 `최근 6개월 기준`을 같은 방식으로 표시한다.
- 숫자 뒤의 `회` 단위는 숫자보다 작게 표시한다.
- PC·모바일 검색량은 월간 검색량 카드 하단에서 분리된 보조 정보로 표시한다.

## 그래프와 표

- 그래프 축 숫자와 날짜의 대비를 높이고 읽을 수 있는 최소 크기를 유지한다.
- 기간별 데이터 표에는 명확한 헤더, 충분한 행 간격, 교차 행 음영을 적용한다.
- 예상 검색량은 굵게, 관심도 지수는 파란색 배지로 표시한다.
- 기존 일간·주간·월간·연간 집계, 기간 자동 확장, 마우스·터치 상세값 동작은 변경하지 않는다.

## 검증

- 요약 카드의 새 문구와 보조 기준 문구가 렌더링되는지 자동 테스트한다.
- 기존 데이터랩 및 스크립트 문법 테스트를 통과해야 한다.
- 데스크톱과 모바일 운영 화면에서 카드·축·표의 줄바꿈과 정렬을 확인한다.
