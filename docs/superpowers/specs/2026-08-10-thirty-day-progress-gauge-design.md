# 30일 진행 게이지 설계

## 목표

대시보드의 업체 카드에서 주차별 5칸 버튼을 계약 시작일 기준 30일 선형 게이지로 교체한다. 게이지는 오늘 날짜에 따라 자동으로 채워지며 현재 주차와 경과 일수를 함께 보여 준다.

## 범위

- 대시보드의 업체 카드만 변경한다.
- 업체의 `startDate`를 Day 1로 사용한다.
- `startDate`부터 오늘까지의 경과 일수를 0~30일로 제한해 게이지 너비를 계산한다.
- 표시 문구는 진행 중에는 `n주차 · n일 / 30일`과 `n일 남음`, 30일 이후에는 `30일 완료`, 시작 전에는 `시작 전`이다.
- 주차 구간은 1~7일, 8~14일, 15~21일, 22~28일, 29~30일로 나눈다. 게이지 아래에는 1~5주차 구간을 표시한다.
- 시작일이 없는 업체는 게이지 대신 시작일 등록 안내를 보인다.

## 보존 사항

- 상세 화면의 주차별 상태 버튼과 `progress` 데이터는 변경하지 않는다.
- 기존 통계 카드의 주차 완료율은 그대로 유지한다.
- 날짜 계산은 로컬 날짜 단위로 처리해 시간대 차이로 인한 하루 오차를 피한다.

## 검증 기준

- 시작 전, 시작일, 7일째, 8일째, 30일째, 30일 초과, 시작일 없음 상태가 모두 올바르게 표시된다.
- 주차별 버튼을 계속 눌러도 30일 게이지 표시는 영향을 받지 않는다.
- 좁은 화면에서도 게이지, 주차 라벨, 경과 일수 텍스트가 겹치지 않는다.
